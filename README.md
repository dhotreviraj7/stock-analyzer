# Indian Stock Analyzer

A website that fetches NSE/BSE stock data, computes technical indicators, backtests
simple strategies, and shows an illustrative (not reliable) next-day direction model.

## ⚠️ Important honesty note
No software can predict stock markets with "high accuracy." This tool gives you real
technical analysis and honest backtesting — the prediction feature reports its own
out-of-sample accuracy (usually 50-55%, barely better than chance) rather than
pretending to be reliable. Use this to learn and analyze, not as financial advice.
